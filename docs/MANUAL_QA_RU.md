# Ручная проверка

В поставке проверены 20 записей, выбранных с seed 42. Неразрешённых расхождений нет. История уточнения суммы лота описана в QUALITY_NOTES.md.

Для нового запуска:

1. Импортируй qa/manual_qa_sample.csv как UTF-8 CSV; все столбцы сначала задай как текст.
2. Открой source_url и сверь тот же notice_id. Сравни title, buyer и страну, основной CPV, дату публикации, дедлайн, сумму процедуры и валюту.
3. Сумма процедуры берётся только из estimated-value-proc. Сумма лота, даже единственного, не заменяет её. Для 674236-2026 сумма 401698.90 PLN указана у LOT-0001; сумма процедуры отсутствует.
4. В *_match укажи match, mismatch или not_applicable. Последнее допустимо только для подтверждённо отсутствующих ожидаемых значений. Заполни review_status=reviewed, reviewed_by, reviewed_at в формате YYYY-MM-DD и пояснения.
5. Не меняй expected_*, snapshot_id, dataset_sha256 и состав выборки. Не переноси проверки на изменённые данные без сверки.
6. Выполни python tools/verify.py и python -m ted_dataset report --run data/runs/2026-10-04 --output delivery для включённой поставки; для нового запуска укажи его пути.

pending или mismatch блокирует готовность результата. Ручная проверка относится к выборке, а не ко всем 300 строкам.
